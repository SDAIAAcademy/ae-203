The defence

Run it, explain a failure, predict a new case

→
3 · Predictthe result of one new case the assessor adds, then run it
The README is the evidence: two measured runs, cost per 1,000 requests and known limits, with the run log and the commits behind them.

Prepare one new case per case study before the day: an Arabizi lost-item message for B, a cancelled trip on a planned-closure day for C, a refund question on a concession fare for A. A wrong prediction explained well scores better than a right one by luck. The defence is 20% of the course grade; the repository rubric is 60%.
